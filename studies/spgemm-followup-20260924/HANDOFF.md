# NVIDIA-node SDK follow-up handoff

Prepared against framework `v2_0` commit `196523eb1e25b832d9f6fa8a665838c042c751e3`, sparse branch `7413ed46fa0f572f4b46e7fd9b7056462a31a770`, and paper `main` `bb7f61ad30873f64ebca758101f5e03d313c37d9`. The experiment revision remained fixed. No manuscript edits or API/model calls.

- **Origin/configuration:** NVIDIA GPU node, Cerebras SDK 2.10.1, simulator revision `8faf87a26e4ea7ca1816636218fe53dd94e4b34a`; one application PE at (4,1), 16×16 FP32 inputs. Exact SDK image SHA-256 is in `sdk-identity.json`.
- **Masked-product result:** six frozen implementations tested on three selection families. Explicit cursor paths selected before final tests; 9/9 final families improve over original merge, geometric mean 1.216×. Selected and baseline each complete 108 correct final launches. This is a manual controlled rewrite, not an agent result.
- **Compiler explanation:** the selected unequal-index path uses conditional register increments instead of the baseline indirect stack-address update. Naming end offsets alone saves no cycles; combining source changes is worse than the selected single rewrite.
- **Full SpGEMM:** two bounded prototypes generate canonical CSR output from arbitrary sparse A×B. Both pass 72 numerical launches plus six capacity/reset checks. Sixteen versus four accumulator slots changes declared scratch from 96 to 24 bytes. Four slots help empty/diagonal inputs and lose on the tested higher-product cases. Output allocation and transfers are excluded; output capacity is preallocated.
- **Independent model check:** 8 correct new launches; exact predicted cycles on all probes: True. The conditional full-row model assigns 25 additional elapsed cycles per output entry at fixed 144 products and fixed row degrees. This is not a universal instruction latency.
- **Trace audit:** 16 exact-binary replays; source/ELF hashes, instruction encodings, timers, outputs, FP operands/results, and product counts checked. Raw traces remain local; full compressed audit and compact tables are committed.
- **IR evidence:** both accepted backend-input IR captures reproduce the measured application ELF byte for byte. The baseline joins cursor addresses with pointer-valued phi nodes; the selected IR keeps updates separate. An external-output filename collision was fixed in the shared capture tool after these measurements; its three regression tests pass.
- **Failures retained:** one rejected IR collection, two initial host copy-argument errors and one tiled-suite 420-second watchdog timeout are archived with hashes. Host correction/checkpoint changes do not alter device code. Watchdog and disassembly-root changes are recorded in amendment files.
- **Artifacts:** `/home/USER/spgemm-followup-20260924`; portable measured build bundles in `replay-bundles.tar.gz`; per-file hashes in `evidence-manifest.json`. Fixtures include CSL, layouts, host interfaces, inputs, and case definitions; see `REPLAY.md` for a fresh SDK run. No active SDK job from this study remains after the final handoff.
